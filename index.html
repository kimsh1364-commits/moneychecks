📖 한투 API 발급 방법
STEP 1
KIS Developers 접속
apiportal.koreainvestment.com 에 접속하세요.
STEP 2
회원가입 / 로그인
한국투자증권 계좌 보유자만 이용 가능합니다.
기존 한투 앱 ID로 로그인하세요.
STEP 3
앱 신청
로그인 후 [open api 서비스 신청] 검색
→ 개인 투자 목적 선택
→ 실전투자 신청 (모의투자 ❌)
STEP 4
앱키 / 앱시크릿 발급
신청 완료 후 [신청현황]에서 확인
→ 앱키(App Key)와 앱시크릿(App Secret)을 복사하세요.
STEP 5
계좌번호 확인
한투 앱 또는 HTS에서 계좌번호 확인
→ 앞 8자리만 입력
→ ISA·개인연금 계좌면 상품코드 22 선택

앱키와 앱시크릿은 절대 타인에게 공유하지 마세요.

이 앱은 본인 브라우저 localStorage에만 저장됩니다.

어떠한 서버에도 영구 저장되지 않습니다.
